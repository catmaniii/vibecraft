VibeCraft 玩家操作指南

VibeCraft Player Guide

你管战略，AI 管执行 · 直接说人话，不用背格式
You command, AI executes · Say it naturally, no rigid format needed
说不清 bot 会反问澄清或提示。带"这里 / 这边 / 这个位置"的指令，要先用小地图把镜头移到目标点 （"这里"= 你当前镜头中心，bot 自动读坐标）。每条下达后在驾驶舱生成一张指令卡片，右上角 × 随时取消。

四层粒度速览

层管什么 · 例子
L1 宏观策略整局打法（剧本）："上 4BG"、"切双矿凤凰"、"转 Skytoss"
L2 全军战术整支军队的姿态："进攻自然"、"全军撤退"、"原地坚守"
L3 单位 / 编队指定单位干活："DT 守气矿别动"、"虚空一队进攻三矿"、"派农民去前线修水晶"
L4 产能 / 经济出兵·补建筑·升级·扩张："造 4 个叉子"、"补 8 BG"、"先研闪烁"、"在这偷矿"
①切剧本②全军姿态③派兵打出去④待命/守点 ⑤巡逻⑥集结点⑦语音编队⑧侦察视野 ⑨产能⑩代理建造⑪偷矿⑫开矿扩张 ⑬技能释放⑭镜头跟随⑮连续指令⑯释放单位⑰维修

① 切剧本 / 宏观打法（L1）

你这样说效果
"上 4BG"、"切双矿凤凰"、"转 Skytoss"、"打航母"切到对应剧本，bot 按它出兵造建筑（三族 40+ 剧本）
"取消剧本"、"先别按剧本走"、"停止刷兵"bot 转保守运营：只补农守家，不主动出门

② 全军战术姿态（L2，对应驾驶舱三个大按钮）

你这样说效果
"进攻对方二矿"、"A 上三矿"、"全军压上去"全军 committed 进攻指定区域（打到底）
"试探进攻二矿"、"推上去看看"、"前压试试"全军试探：占便宜就占，打不动就撤
"强攻 / 一波流 / 不要命冲"all-in 强冲，不撤
"守家"、"全部回家防守"、"守一波"全军回主基地一线防守
"持续守家姿态"、"保持防守"一直保持守家姿态
"全军撤退"、"全部撤回基地"、"回家"全军撤回（普通移动，遇敌不恋战）
"原地坚守"、"守住别动"、"到斜坡堵口"聚团到指定点站住不回家
全军命令只作用自由单位；被你单独点名 / 编了队的单位不受影响（要它听全军命令先取消那条独占）。

③ 派兵打出去：进攻 / 骚扰 / 火力侦查（L2-L3）

你这样说效果
"派 5 个凤凰去骚扰对方主基地"、"飞龙骚扰对面上边分矿"指定数量去骚扰（骚扰必须说数量，否则反问）
"凤凰打死对方 5 个农民就回"骚扰带退出条件（杀够就撤）
"火力侦查对方三矿"、"派 4 个追猎前压看看"小股前压试探，占便宜 / 损耗大 / 超时任一就退
"残血的追猎撤回来"、"盾破的虚空拉回基地"按状态选单位撤退
"前线那个追猎撤退"、"最前面的叉子退回来"、"后面那个不朽顶上去"按当前物理位置选最前 / 最后那个

④ 单位待命 / 集结 / 守点 / 站桩（L3）

你这样说效果
"派一个农民到这里待命"、"叉子到对方三矿待命"移到目标点留守，受敌还击、战后归位（持续到 ×）
"所有虚空到这里集中"、"叉子都聚过来这里"把现有这批兵聚到一点独占停留
"DT 守气矿别动"、"探机守瞭望塔别动"钉在原地守住（hold，不主动出击）
"2 个追猎去守 5 点分矿"、"叉子在 7 点守"守某区域（受敌还击并归位，guard）
"派一个追猎站左边瞭望塔"、"使徒去右边瞭望塔"占瞭望塔（watchtower / 左 / 右）
"让农民蹲对方右下分矿"、"探机去对方 11 点盯着"蹲点放视野（方位词 / 钟点都认）

⑤ 巡逻（两点往返，L3）

你这样说效果
"农民在对方 11 点分矿和三矿之间巡逻"单位在两点之间持续往返
"3 个凤凰在自然和对方主基地之间巡逻"多单位巡逻线
"追猎在这里和对方三矿之间巡逻"第一个点用"这里"（当前镜头）

⑥ 出兵集结点（rally，管未来新出的兵，L3）

你这样说效果
"集结点设在这里"、"以后出的兵都到这里集合"、"新兵集结点放这"设全局集结点：之后新造出来的兵默认去那（不动现有兵）
区别："〈某兵种〉到这里集中"是把现有的兵聚过去（④）；"集结点 / 出兵都去"是管未来新兵去哪（⑥）。

⑦ 语音编队（1-5 队，L3）

你这样说效果
"把运输机编成 1 队"、"运输机 1 队"把这批单位编进 1 队（编队条显示成员）
"把 2 个农民编成 3 队"只编指定数量进队
"以后新出的虚空都编入 1 队"、"将来造的追猎自动加 2 队"持续征兵：新出的兵自动入队
"1 队进攻对方三矿"、"2 队火力侦查这里"、"3 队撤退"直接对某队下指令
"释放 2 队"、"取消 2 队"、"清除 2 号队"解散编队，单位交还 bot

⑧ 侦察 / 视野（L2-L3）

你这样说效果
"看一眼对方主基地"、"侦察一下二矿"、"扫一下三矿"派 1 单位走一趟，拿到视野即收工
"盯着对方主基地"、"保持二矿视野"、"持续看对方升科技"持续保持某区域视野
"派探机侦察 11 点"指定单位去某方位 / 钟点侦察
"让探路农民回来"、"探路兵别探了"撤回正在探路的农民（回家采矿）
"探路农民别探了，去占右边瞭望塔"把探路农民改派去做新任务（不回家）

⑨ 出兵 / 补建筑 / 升级 / 暂停产线（L4 产能）

你这样说效果
"出 2 个哨兵"、"造 4 个叉子"、"出 2 叉子加 3 追猎"加产指定兵种数量（出齐即消）
"刷两个叉子到前线"、"折跃 3 追猎去二矿"折跃门直接把新兵生产到指定落点
"补一个 BF"、"补两个 VS"、"再来一个气矿"增量补建筑（在 N 个基础上 +N）
"补到 8 个 BG"、"凑齐 14 个 BG"补到绝对总数
"二矿补 2 气矿"、"ramp 放 2 炮 1 BF"指定地点补建筑
"先研闪烁"、"升级地面攻击"、"补个 BY 然后升空军攻防"研究升级（"攻防"= 攻击 + 护甲两条）
"暂时不出追猎"、"停止造叉子"、"先别造哨兵"暂停某兵种产线（× 才恢复）

⑩ 野建筑 / 代理建造（派农民出去建，L3-L4）

你这样说效果
"派农民去前线修个水晶"派 1 农民去目标点修水晶，全程不被拉走，建完留原地待命
"派农民去对方 6 点分矿修个水晶，水晶好了在旁边修个 BG"链式：先水晶，水晶好后在能量场内接着修后续建筑
"派个农民去这里修个水晶，然后修两个 VS""这里"= 当前镜头；水晶 + N 建筑用同一农民依次建
"再到这里修一个 VS"复用正在外面建造的那个农民，追加一个建筑
神族机制：后续建筑必须在水晶能量场内，所以代理建造总是先水晶、再建筑，bot 自动排位不撞格。

⑪ 偷矿（隐蔽采矿点，L4）

你这样说效果
"在这偷矿"、"在这里偷一个矿"、"开隐蔽基地"先移镜头到目标矿区再说 —— 派约 16 农民隐蔽采矿，受攻击自动逃
"在这偷矿，多派点农民"、"偷个矿给 20 个农民"调农民数（默认 16，最多 24）
"在这偷矿，不要偷气"只偷矿不偷气

⑫ 开矿 / 扩张（L4）

你这样说效果
"在这开矿"、"在这下主基地"、"这片矿开了"看着矿区说 —— 派农民去下基地开矿（落点自动摆正，太歪弹确认）
"再开个矿"、"扩一个"、"开三矿"不指地点 —— bot 自选下一个分矿点扩张

⑬ 高难技能释放（必须你手动下令，L3）

你这样说效果
"给两个 BF 星空加速"、"给星门加速"Nexus 对建筑放星空加速（chrono）
"所有电兵合成白球"、"合 2 个白球"高坦两两合体成白球（Archon）
"电兵放心灵风暴到对方主基地"HT 放风暴（要给落点）
"叉子闪到对方主基地"、"闪追闪进去"追猎闪烁（需 Blink 已研）
"枪兵嗑药冲"（人族）、"飞蛇拉对面航母"（虫族）兴奋剂 / abduct 等各族技能

⑭ 镜头跟随（L3，只动镜头不动兵）

你这样说效果
"镜头跟着大部队"、"看主力部队"镜头跟全军质心
"镜头跟着追猎"、"盯住那个凤凰"、"跟随母舰"跟某兵种
"跟着火力侦查那波"、"跟骚扰小队"跟当前侦查 / 骚扰小队
"镜头跟随探路农民"、"跟守瞭望塔的"、"跟巡逻的"按任务身份跟（不是跟同名采矿单位）

⑮ 连续指令 / 多步串联（L3）

你这样说效果
"农民先去右瞭望塔，再去对方 11 点，然后在对方二矿修个水晶，最后回家采矿"一个农民按顺序走多步，每步完成自动触发下一步

⑯ 释放 / 撤回单位

你这样说效果
"那个叉子回来"、"释放所有虚空"撤销该单位身上所有在途指令，完全交还 bot

⑰ 维修（人族，派农民修血，L3-L4）

你这样说效果
"派 3 个农民修大舰"、"派两个农民修指挥中心"派指定数量 SCV 去修，修满后自动完成（持续到 ×）
"修一下那个地堡"、"修地堡"不带数量默认派 3 个农民修
"家里残血的坦克都修一下"、"残血大舰都修"按类型/状态修一批，全部满血后完成
仅人族（SCV 才能修），且只能修机械单位 / 建筑（枪兵等生物兵不能修）。

别名约定

建筑用 hotkey 缩写（BG=兵营 / BE=水晶 / VR=机械台 / VS=星门 / BY=控制核心 …）， 单位用中文黑话（叉子 / 不朽 / 追猎 / 闪追 / DT / 小狗 / 刺蛇 / 飞龙 …），战术黑话保留（4BG / IAC / Skytoss / 12pool / 两矿凤凰 …）。 说了非本族单位 / 建筑会被友好拒绝。

玩家控制权（四条规则）

1单位级指令 = 独占 + 最新覆盖：给已被控制的单位下新指令会抢占它。
2全军命令不碰被独占的单位：只作用自由单位；要它听全军命令先取消独占 / 解散编队。
3释放 / 解散单位 → 撤销它身上所有在途指令，还给 bot。
4撤退用普通 move（遇敌不恋战），不 attack-move。
优先级金字塔：没你的指令 → bot 全自决；你锁住的部分 bot 不动、其余仍自主；你撤销 → 决策权浮回来。
If a command is unclear the bot will ask for clarification. For commands using "here / this location", first pan the minimap to the target point ("here" = your current camera center; the bot reads the coordinates automatically). Each command generates an instruction card in the cockpit — tap × in the top-right to cancel at any time.

4-Layer Command Summary

LayerWhat it controls · Examples
L1 Macro StrategyFull-game build (recipe): "4BG", "switch to dual-expansion Phoenix", "go Skytoss"
L2 Tactical CommandWhole-army stance: "attack natural", "full retreat", "hold position"
L3 Unit / GroupSpecific units: "DT guard gas don't move", "Void group 1 attack third", "send probe to build BE forward"
L4 Production / EconomyUnits · buildings · upgrades · expand: "make 4 Zealots", "add 8 BG", "research Blink", "hidden mine here"
①Strategy②Stance③Attack/Harass④Standby ⑤Patrol⑥Rally⑦Groups⑧Scout ⑨Production⑩Proxy Build⑪Hidden Mine⑫Expand ⑬Abilities⑭Camera⑮Chaining⑯Release⑰Repair

① Strategy / Build (L1)

Say thisEffect
"4BG", "switch to dual-expansion Phoenix", "go Skytoss", "play Carriers"Switch to the corresponding build; bot produces units and buildings (40+ builds across all 3 races)
"cancel build", "stop following the build", "stop training units"Bot enters conservative mode: only makes workers and defends at home

② Tactical Stance (L2 — the 3 big cockpit buttons)

Say thisEffect
"attack their second", "A-move their third", "push all in"Full army committed attack on the target area (fights to the end)
"probe-attack second", "push to check", "poke forward"Probe / feint: take advantage if possible, retreat if too costly
"all-in", "one-base all-in", "reckless push"All-in rush, no retreat
"defend at home", "all units back to defend", "hold a wave"Entire army returns to defend the main base line
"keep defending", "maintain defensive stance"Persistent defensive posture
"full retreat", "all units back to base", "come home"Army retreats (normal move, does not engage)
"hold here", "don't move", "block the ramp"Cluster at the target point and hold — does not return home
Army-wide commands only affect free units. Units claimed by individual or group orders are unaffected — cancel their claim first to include them.

③ Sending Units Out: Attack / Harass / Probe (L2-L3)

Say thisEffect
"send 5 Phoenix to harass their main", "Mutalisk harass their top expansion"Designated quantity sent to harass (harass requires a count, otherwise bot will ask)
"Phoenix retreat after killing 5 workers"Harass with exit condition (retreat after enough kills)
"probe-attack their third", "send 4 Stalkers to poke forward"Small-force probe: retreat if taking too many losses or time runs out
"retreat the low-HP Stalkers", "pull back the shieldless Void Rays"Select units by status and retreat
"retreat the front-line Stalker", "fall back the leading Zealot", "push the rear Immortal forward"Select unit by physical position (front / rear)

④ Unit Standby / Rally / Guard / Hold (L3)

Say thisEffect
"send a probe here to standby", "Zealot standby at their third"Move to target point and stay; fight back if attacked, return after combat (until ×)
"all Void Rays group up here", "Zealots gather over here"Cluster current units to a single point (claimed, stays there)
"DT guard the gas don't move", "Observer guard the watchtower don't move"Hold position (hold — does not proactively engage)
"2 Stalkers guard the 5 o'clock expansion", "Zealot guard 7 o'clock"Guard an area (fight back and return; guard)
"send a Stalker to the left watchtower", "Sentry go to right watchtower"Capture watchtower (left / right / by name)
"park a worker at their lower-right expansion", "Observer at their 11 o'clock watching"Vision-scouting spot (accepts cardinal directions and clock positions)

⑤ Patrol (two-point back-and-forth, L3)

Say thisEffect
"worker patrol between their 11 o'clock expansion and third"Unit continuously shuttles between two points
"3 Phoenix patrol between our natural and their main"Multi-unit patrol line
"Stalker patrol between here and their third"Use "here" for the first point (current camera position)

⑥ Rally Point (for future units, L3)

Say thisEffect
"set rally point here", "all new units meet here", "rally new units to this location"Sets the global rally point: newly trained units will go there by default (does not move existing units)
Difference: "〈unit type〉 gather here" moves existing units (④); "rally / new units go to" controls where future units report (⑥).

⑦ Voice Groups (1-5, L3)

Say thisEffect
"put the Medivacs into group 1", "Medivac group 1"Add these units to group 1 (group bar shows members)
"put 2 probes into group 3"Add only the specified count to the group
"add all future Void Rays to group 1", "auto-add new Stalkers to group 2"Auto-conscript: newly trained units join the group automatically
"group 1 attack their third", "group 2 probe-attack here", "group 3 retreat"Issue commands directly to a numbered group
"disband group 2", "cancel group 2", "clear group 2"Dissolve the group; units returned to bot control

⑧ Scouting / Vision (L2-L3)

Say thisEffect
"check their main", "scout their second", "scan their third"Send 1 unit on a one-time pass; done once vision is obtained
"keep watching their main", "maintain vision at second", "watch for tech upgrades"Persistent vision on an area
"send Observer to scout 11 o'clock"Specified unit scouts a direction / clock position
"scout probe come back", "stop scouting"Recall scouting worker (returns to mine)
"scout probe stop scouting, go take right watchtower"Redirect scouting worker to a new task (does not return home)

⑨ Train / Build / Upgrade / Pause (L4 Production)

Say thisEffect
"train 2 Sentries", "make 4 Zealots", "train 2 Zealots and 3 Stalkers"Queue the specified unit count (auto-completes when done)
"warp 2 Zealots to the front", "warp 3 Stalkers to second"Warp Gate: train units directly at the target location
"add a BF", "build two VS", "add another gas"Incremental build (adds N on top of current count)
"build up to 8 BG", "get to 14 BG total"Build to an absolute total
"build 2 gas at second", "place 2 cannons and 1 BF at the ramp"Build at a specified location
"research Blink", "upgrade ground attack", "build BY then upgrade air attack and armor"Research upgrades ("attack and armor" = both attack and armor lines)
"pause Stalker production", "stop making Zealots", "hold off on Sentries"Pause a unit's production line (resume with ×)

⑩ Proxy / Forward Build (send probe out to build, L3-L4)

Say thisEffect
"send a probe to build a BE forward"Send 1 probe to the target point to build a Pylon; probe stays on site after completion
"send probe to enemy 6 o'clock to build BE, then build BG next to it"Chain: Pylon first, then build follow-up structures inside the power field
"send a probe here to build a BE then two VS""here" = current camera; same probe builds Pylon + N buildings in sequence
"add one more VS at that location"Queue one more building for the probe already working forward
Protoss mechanic: subsequent buildings must be inside a Pylon power field, so proxy builds always start with a Pylon, then the buildings. The bot spaces them automatically so they don't overlap.

⑪ Hidden Mine (covert mineral line, L4)

Say thisEffect
"mine here secretly", "set up a hidden base here", "covert expansion here"Pan camera to the target mineral field first — sends ~16 workers to mine covertly; auto-flee on attack
"hidden mine here, more workers", "20 workers at the hidden mine"Adjust worker count (default 16, max 24)
"mine here without gas"Mine minerals only, skip gas

⑫ Expand (L4)

Say thisEffect
"expand here", "drop Nexus here", "take this mineral line"While looking at the mineral field — sends a worker to build a base (auto-aligns; prompts if misplaced)
"take another expansion", "expand one more", "take third"No location specified — bot picks the next best expansion slot

⑬ Difficult Abilities (must be issued manually, L3)

Say thisEffect
"Chrono two BF", "Chrono the Stargate"Nexus Chrono Boost on buildings
"merge all HT into Archons", "merge 2 Archons"Merge High Templar pairs into Archons
"HT Psionic Storm their main"High Templar casts Storm (target location required)
"Blink Stalker into their main", "Blink all in"Stalker Blink (Blink upgrade required)
"Stim Marines push" (Terran), "Viper pull their Carrier" (Zerg)Stim / Abduct and other race-specific abilities

⑭ Camera Follow (L3 — camera only, no unit movement)

Say thisEffect
"follow my main force", "watch the main army"Camera follows the center of mass of the full army
"follow the Stalkers", "track that Phoenix", "follow the Carrier"Follow a unit type
"follow the probe squad", "track the harass group"Follow the current scouting / harassing squad
"follow the scouting probe", "follow the watchtower guard", "follow the patrol"Follow by role (not the same-type units that are mining)

⑮ Chaining / Multi-Step Commands (L3)

Say thisEffect
"probe: go to right watchtower, then enemy 11 o'clock, then build BE at their second, then come home to mine"One probe executes multiple steps in order; each step auto-triggers when the previous completes

⑯ Release / Recall Units

Say thisEffect
"that Zealot come back", "release all Void Rays"Cancel all in-flight orders on that unit; fully return it to bot control

⑰ Repair (Terran — send SCV to repair, L3-L4)

Say thisEffect
"send 3 workers to repair the Battlecruiser", "2 workers repair the Command Center"Send the specified count of SCVs to repair; completes automatically when full HP (until ×)
"repair that Bunker", "fix the Bunker"No count specified → 3 SCVs by default
"repair all damaged Tanks at home", "fix low-HP Battlecruisers"Repair a group by type/status; completes when all are at full HP
Terran only (SCV mechanic). Can only repair mechanical units / buildings — biological units like Marines cannot be repaired.

Alias Conventions

Buildings use SC2 hotkey abbreviations (BG=Gateway / BE=Pylon / VR=Robotics / VS=Stargate / BY=Cybernetics Core…). Units use SC2 community names (Zealot / Immortal / Stalker / Blink-Stalker / DT / Zergling / Hydralisk / Mutalisk…). Tactical jargon is preserved (4BG / IAC / Skytoss / 12pool / two-base Phoenix…). Issuing commands for the wrong race's units or buildings will result in a polite rejection.

Player Control Model (4 Rules)

1Unit-level order = exclusive + latest overrides: issuing a new unit-level order on an already-controlled unit seizes it.
2Army-wide commands do not touch claimed units: only affects free units; cancel the individual claim first to include them.
3Releasing / disbanding a unit cancels all its in-flight orders and fully returns it to the bot.
4Retreating uses normal move (does not engage enemies), not attack-move.
Priority pyramid: no commands from you → bot decides everything; what you lock the bot can't touch, the rest remains autonomous; you cancel → control floats back.
