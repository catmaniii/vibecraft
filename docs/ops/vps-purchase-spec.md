# VibeCraft 多人会合服务器 · VPS 采购说明（给购买代理用）

> 用途：给浏览器 Claude 插件 / 代购代理照此**下单一台云虚拟机**。看懂"首选方案"
> 直接买即可；配置在"硬性要求"的范围内就算合格。

## 一句话用途

部署一台**香港**云服务器，跑 SC2 远程多人对战的 **WebRTC 信令会合 + STUN + coturn(TURN) 中继**，
要求**中国大陆和海外都能访问**。所以选香港（免 ICP 备案、对华网络好），不要大陆地域，也不要
AWS/GCP（对华差）。

## 首选方案（直接买这个）

- **厂商**：阿里云 **轻量应用服务器**（Simple Application Server）
- **地域**：**中国香港（Hong Kong）** — 必须是香港，不是大陆任何地域
- **套餐参数**（挑最接近的档）：
  - vCPU：**2 核**（1 核也能跑，但 2 核更稳）
  - 内存：**2 GB**
  - 系统盘：**≥40 GB SSD**
  - **峰值带宽：≥30 Mbps**（中继视频吃带宽，这条重要）
  - **月流量包：≥1 TB**（出方向计费；中继流量主要靠它）
  - 操作系统镜像：**Ubuntu 22.04 LTS**（或 24.04 LTS）—— 纯净系统，不要带宝塔/控制面板的镜像
- **公网 IP**：必须自带**固定公网 IP**（轻量应用服务器默认就有，确认不是"仅私网"）
- **预算**：约 **¥60–110/月** 属正常；超过 ¥150/月请停下来确认

## 可接受的等价替代（首选买不到时）

按优先级：
1. **腾讯云 轻量应用服务器 · 香港**，同规格（2C2G / ≥40G / ≥30Mbps / ≥1TB流量 / Ubuntu 22.04）
2. **阿里云 ECS · 香港**，突发性能实例 t6/e 系列，2C2G / Ubuntu 22.04 / ≥40G SSD /
   按量或包月带宽 ≥30Mbps（ECS 流量按量计费，注意成本，优先还是选轻量的流量包模式）
3. 腾讯云 CVM · 香港，同上

## 硬性要求（合格判据，任一不满足就别买）

- [ ] 地域 = **香港**（境外、免备案）
- [ ] 有**固定公网 IPv4**
- [ ] OS = **Ubuntu LTS**（22.04 / 24.04），纯净镜像
- [ ] vCPU ≥ 1（推荐 2）、内存 ≥ 1 GB（推荐 2 GB）
- [ ] 峰值带宽 ≥ **30 Mbps**
- [ ] 月流量 ≥ **1 TB**（或选固定带宽套餐，带宽 ≥30 Mbps 也可）
- [ ] 系统盘 ≥ 40 GB
- [ ] **不要**大陆地域、**不要** AWS/GCP/海外小厂、**不要**预装宝塔等面板的镜像

## 不要做的事

- 不要勾选大陆地域（要 ICP 备案，办起来很麻烦）
- 不要买"流量按量计费、无流量包"的裸 ECS（中继超量很贵）；优先轻量的"流量包"模式
- 不要买最低配 0.5C/512M 的超迷你档（coturn + TLS 容易吃紧）

## 端口需求（购买后由我配置，列此供参考，不影响下单）

下单时不用管防火墙，买完我会开这些口：
| 端口 | 协议 | 用途 |
|---|---|---|
| 22 | TCP | SSH 管理 |
| 443 | TCP | TURN over TLS（turns:）+ WSS 信令（穿中国防火墙的关键） |
| 3478 | UDP+TCP | STUN / TURN |
| 5349 | TCP | TURN over TLS |
| 49160–49260 | UDP | TURN 媒体中继端口段 |

## 购买后还需准备（与本次下单无关，单独处理）

- 一个**域名**（或子域名）解析到这台机器的公网 IP —— 给 `turns:443` 的 TLS 证书用
  （Let's Encrypt 自动签发）。如果已有域名，加个 A 记录即可，无需单独买。

## 交付给我什么（买完后）

把这几样发我即可开始部署：
1. 公网 IP
