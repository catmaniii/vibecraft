# Zerg 宏观开局（17 Hatch / Macro Hatch）深度调研

> 研究日期：2026-05-23
> 来源：Spawning Tool、Liquipedia、顶级选手复盘

---

## 核心前提：什么是"17 Hatch / Macro Hatch"

"17 Hatch"指在**17 supply** 时将探机送去建二矿孵化场（BH），在 18 supply 建气矿（BE），同在 17 supply 建母池（BS）——三个建筑几乎同时开工，确保最早的二矿落地。

"Macro Hatch"是另一个含义：在**已有的主基地或自然矿区内再建一个额外孵化场**，纯粹用于增殖幼虫产量（不对应新基地）。这是虫族宏观流中期的标配操作，ZvP 通常在 60 农民达标后在主基地补建。

本文以"17 Hatch 宏观开局"为主线，兼顾中后期 Macro Hatch 节点。

## 中期：Lair / 进攻建筑顺序

三矿经济稳定后（约 36-44 农民），按对局分支：

| — | ~5:30+ | 滑行器改造（Glial Reconstitution，ZvT 优先） |

### ZvP 变体（3 BH before gas / Reynor-Shin 风格）

ZvP 对应高塔体系（BF / Forge 开局），经典"3孵化场先于气矿"流派节奏更慢、更暴力：

| 时间 | 动作 |
|------|------|
| ~6:00 | 开两气（延迟气矿是 ZvP 特有！） |
| ~6:15-7:00 | BR + BV（进化腔） |
| ~6:30 | Lair |
| — | 60 农民目标：8:00 前 |
| — | 主基地加建 Macro Hatch（农民 60 后） |
| 11-12 min | 满兵（蟑螂重 + 蟑螂/跳虫主力），准备出门 |

Reynor-Shin 风格走 **+1 重甲跳虫**（ling-heavy + bane，配 hydra）：
- 进化腔 ~4:20，+1 近战武器 4:50 完成
- 刺蛇巢（VH / Hydralisk Den）~5:24，刺蛇 6:25 开始出
- 跳虫巢（BB / Baneling Nest）~5:54

### ZvT 变体（蟑螂 / 刺蛇主路）

ZvT 面对海陆空 MMM 压制：

| 时间 | 动作 |
|------|------|
| ~3:47 | BR 蟑螂窝 |
| ~4:05 | Lair |
| ~4:30 | 滑行器（Glial Reconstitution）—— ZvT 核心，蟑螂机动性 |
| ~4:30 | 开始量产蟑螂 |
| ~5:00-5:30 | 第四矿 BH |
| 5-6 min | 侦察生物弹/机械分支，决定是否换刺蛇 |

"出门一波"时机：**7-9 分钟**，满 200 supply 蟑螂/跳虫/刺蛇组合（Serral 最速 10:50 满兵，标准段位 12:00）。

### ZvZ 变体（快蟑螂 / 飞龙对抗）

ZvZ 节奏最快，17 Hatch 有被 12pool 或 pool-first 打穿风险，因此：
- **更激进分支**：pool-first（Reynor ZvZ 常用 16 pool → 17 hatch 变种）
- **防守分支**：17 Hatch 但提前 BC（刺蛇匍匐者 / Spine Crawler）守门口
- 三矿时机推迟到蟑螂压制对方之后

## Macro Hatch（额外孵化场）节点

| 场景 | 时机 | 位置 |
|------|------|------|
| ZvP 宏观流 | 60 农民之后（约 8 min） | 主基地 |
| ZvT Serral 宏观 | 第四矿 + 第五孵化场 ~6:11 | 主基地或三矿 |
| 通用 | 有 300 矿富余时随时补 | 任意已有基地内 |

目的：增殖幼虫注射频次，确保 200 supply 满兵不掉单位产能。

## 顶级选手 benchmark

- **Serral（ZvT/ZvP）**：13 OL → 17 Gas → 17 BS → 18 BH；四矿 + 第五 Macro Hatch 约 6:11；蟑螂出门 7-9 min；最快满兵 10:50 min
- **Reynor（ZvT pool-first）**：13 OL → 16 BS → 17 BH → 6 ling + 蜂后；比 17 Hatch 更偏激
- **Reynor-Shin（ZvP hydra-bane）**：16 BH 宏观 + +1 重甲跳虫 → 刺蛇 + 跳虫 army；8 min 前完成 army 集结
- **Dark（ZvP）**：三矿 before gas 体系；60 农民 → Macro Hatch → 蟑螂满 → 12 min 出门
